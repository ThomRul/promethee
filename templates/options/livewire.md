# Option Livewire

Ajouter livewire/livewire 4.4.7 avec Composer et le skill qualifié livewire-development. Adapter resources/js/app.js pour ne pas importer/démarrer Alpine une seconde fois. Utiliser l’intégration documentée de Livewire 4 ; choisir le mode Vite seulement si nécessaire. Les assets, routes et composants métier restent à créer par l’agent. Vérifier l’absence de double instance Alpine dans le navigateur.
